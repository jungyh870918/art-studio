## 2. 초상화 슬롯 — **189 다. 이게 의도값이다** ⚠ 발주 규격을 189로

측정해 준 「약 194」는 액자 선(설계 1px → 화면 3px)이 상자 바깥으로 반씩 걸쳐 나간 것이
±6px 오차와 겹친 값이다. 이미지가 들어가는 상자는 **189×189** 다.

```
PORTRAIT_SIZE = 63 설계 픽셀  ×  UI 배율 3  =  189 화면 픽셀
```

**188로 맞출 수 없다.** 188 / 3 = 62.667 이라 설계 좌표가 정수가 아니게 된다 —
D1을 942×1674로 올린 것과 같은 이유다.

| 설계 px | 화면 px | 목업 실측 189 | 발주 규격 188 |
|---|---|---|---|
| 62 | 186 | −3 | −2 |
| **63** | **189** | **±0** | +1 |
| 64 | 192 | +3 | +4 |

**63이 유일하게 목업 실측과 정확히 일치한다.** 발주 규격을 **189×189** 로 바꿔 달라 —
188은 189를 반올림한 값이었고, 원래 잰 값으로 돌아가는 것이다.

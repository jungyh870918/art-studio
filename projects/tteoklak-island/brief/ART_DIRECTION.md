## 1. 최상위 기준은 그림이다

**문서와 목업이 충돌하면 목업이 이긴다.** (디렉터 결정 2026-08-12)

목업 4장: `../references/01_explore` · `02_dialogue` · `03_battle` · `04_notebook`

이 넷은 도달 목표이자 **생성할 때마다 첨부하는 스타일 앵커**다.
화풍을 문장으로 설명하지 않는다 — 그림이 대신 말한다.

## 2. 화풍 — 측정값으로

목업을 재서 나온 값이다. 「어떤 느낌」이 아니라 파일에서 읽은 것.

| | 측정 |
|---|---|
| 크기 | 941×1672 (4장 전부) — **9:16 정확**, 오차 0.05% |
| 업스케일 배수 | **1×** — 픽셀 격자가 없다 |
| 고유색 | 148,311 ~ 248,133 |
| 반투명 픽셀 | **0** — 부품이 아니라 완성된 화면이다 |

→ **도트가 아니다.** 픽셀아트처럼 보이는 고해상도 일러스트다.
「320×180 진짜 도트 · 제한 팔레트 32~48색 · 안티앨리어싱 금지」는 전부 폐기됐다.

## 3. 뒤집히지 않은 것

- **자리표시자 폴백** — 그림이 없으면 코드가 그린다. 중간 상태에서 게임이 깨지지 않는다
- **데이터 주도** — 장면·룰 129개·대사 827줄은 그림과 무관하다
- **Galmuri 도트 폰트** — 목업 속 UI 글자가 도트체다. 폰트는 그림이 지지한다
- **Pixel Modernism** — 형태는 현대적, 재료는 레트로 (기획서 §06)

## 4. 배경에 걸리는 규칙

화면마다 월드 높이가 다르다 (탐색 **78.6%** · 대화 **47.8%** · 배틀 **44.0%** · 수첩 0%).
그래서 배경은 **넉넉히 그리고 화면이 세로로 잘라 쓴다.**

> **2026-08-17 정정** — 대화 화면을 「58%」로 적었는데 재보니 **47.8%**다.
> 배틀은 애초에 재지 않았다. 측정값은 [`MOCKUP_UI_AUDIT`](MOCKUP_UI_AUDIT.md) §7.
> 대화 장면 배경은 예상보다 **10%p 덜 보인다** — 아래 「73%」 규칙이 대화 장면에도
> 그대로 맞는지는 셸이 올라간 화면에서 확인해야 한다.

> 인물이 걸어다니는 **바닥 띠가 화면 세로 60~95%** 에 들어오고,
> 그 띠의 위쪽 끝이 **73%보다 내려가지 않아야 한다.**
> 아래가 UI에 덮이므로, 맨 아래에 두면 대화 중에 인물이 화면 밖으로 나간다.

비율은 **2:3 또는 그보다 세로로 길게**, 폭 1024px 이상.
(화면 비율 9:16 이 아니다 — 배경이 맞춰야 하는 것은 월드 영역 비율 0.72다)

## 5. 생성 규칙 R1~R8 (요약)

정본은 기획서 §23.

| | |
|---|---|
| R1 | 화면을 통째로 시키지 않는다. **부품으로 받는다** |
| R2 | 화풍은 문장이 아니라 **앵커 이미지**로 지정한다 |
| R3 | 프롬프트는 고정 블록 + 가변 블록. 손으로 타이핑하지 않는다 |
| R4 | 주문 하나 = 새 대화 하나. 다만 같은 날에 몰아서 |
| R5 | 소스를 섞지 않는다 |
| R6 | **한 번에 여러 장 받아 고른다** |
| R7 | **판정은 사람이 눈으로 한다.** 코드는 크기·알파 같은 객관적인 것만 |
| R8 | 최종 판정은 게임 화면 위에서 |

## 6. 스튜디오가 지켜야 할 격리

`CLAUDE.md` §6 「스타일은 자동으로 전염시키지 않는다」의 이 프로젝트판.

- **구매 에셋을 이 게임의 앵커나 소재로 쓰지 않는다.** 화풍이 다르고, 대부분 라이선스가 AI 입력을 금지한다
- **이 게임의 생성물을 2d-assets 파이프라인에 넣지 않는다.** 그쪽은 도트·벡터 세계다
- 2d-assets에서 가져오는 것은 **구조**뿐이다 (전략 §7)

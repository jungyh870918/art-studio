# references — 세 묶음의 지위가 다르다

`docs/03_PROJECT_STRUCTURE.md` §10 — 「레퍼런스는 공식 자산이 아니다. 여기에 저장되었다는
사실이 그 이미지를 복제 대상으로 만들지 않는다.」

이 프로젝트는 그 위에 **한 겹 더** 구분이 필요하다. 세 묶음이 서로 다른 역할을 한다.

| 폴더 | 지위 | 어떻게 쓰는가 |
|---|---|---|
| `mockups/` | **도달 목표** | 화면이 어디로 가야 하는지. 인상·배치·색의 근거 |
| `current-build/` | **현재 상태** | 지금 실제로 도는 화면. 무엇을 대체하는지의 기준선 |
| `original-koei/` | **화면 문법의 뿌리** | 정보 배치와 조작 문법만. **그래픽은 절대 쓰지 않는다** |

## mockups/ — 도달 목표

`~/Desktop/Projects/three-kingdoms/docs/mockups/` 사본. 941×1672 (정확히 9:16).
`m1` 천하 · `m2` 도시 · `m3` 무장 · `m4` 전투. `-full` 이 원본, 나머지는 760×1350 축소본.

**ChatGPT 가 한 장씩 뽑은 완성 그림이다. 재현 가능한 규격이 아니다.**

- 인상과 배치의 근거로 쓴다
- **여기서 타일이나 아이콘을 잘라내지 않는다** — 픽셀 격자가 없다.
  측정 근거: `../reviews/2026-08-17_mockup-spec-recovery/FINDINGS.md` §1
- 배율·타일 크기·아이콘 그리드를 여기서 «측정»했다고 말하지 않는다

## current-build/ — 현재 상태

`docs/shots/` 사본. 1280×800 가로. 내부 640×400 을 2배 확대한 절차적 도트.

- **이것도 레퍼런스이지 승인 자산이 아니다.** 다만 「지금 실제로 도는 화면」이라는
  다른 어떤 자료도 갖지 못한 지위가 있다
- 목업으로 갈아탈 때 **무엇을 잃는지** 확인하는 데 쓴다 (계절 4종 · 데스크톱 조작 등)
- 격자 검출 대조군으로도 쓰였다 (내부 2배 배율이 lag 2 로 정확히 검출됨)

## original-koei/ — 그래픽 사용 금지

코에이 『삼국지Ⅲ』(1992) 검색 결과 스크린샷 4장.

> **이 프로젝트의 못 박힌 규칙 — 원작 그래픽 무단 사용 금지.**
> 게임 저장소가 발주서 §4 에서 명시했다.

- **참고하는 것** — 정보를 화면에 놓는 문법, 명령 계층의 형태, 전략 게임이 수치를
  읽히게 만든 방식
- **참고하지 않는 것** — 픽셀 그 자체, 팔레트, 초상, 지도 그래픽, UI 프레임의 형태
- 생성기에 **입력으로 넣지 않는다.** `CAPABILITY_2D_ASSET_FACTORY.md` §11 의
  「구매 에셋을 생성 AI에 입력으로 넣지 않는다」와 같은 이유이며, 여기서는 더 강하다

# 배경 통합 시험 — 2026-08-17

받은 배경을 **실제 게임에 넣고 화면을 찍었다.** 파일 판단으로 끝내지 않는다는 원칙
(`docs/08_REVIEW_AND_APPROVAL` §11, `docs/10_ENGINE_HANDOFF` §9)을 따른 것이다.

- 대상: `candidates/backgrounds/01_bull_harbor.png` (1024×1536)
- 게임: `secret-of-falling-island` · Godot 4.7.1
- 방법: `assets/backgrounds/bull_harbor_entrance.png` 로 넣고 `--import` 후
  `tests/Screenshots.tscn` 으로 촬영. 시험 후 저장소는 원상복구했다

## 먼저 확인된 것 — 폴백은 작동한다

파일 하나를 규격 경로에 넣었을 뿐인데 **코드 수정 없이 로드됐다.**
장면 데이터의 `background` 필드가 이미 그 경로를 가리키고 있었다.
「그림이 없으면 자리표시자, 있으면 그림」 구조는 설계대로 동작한다.

## 01_squashed — 그대로 넣기

세로 1024×1536(비율 0.667)을 가로 320×135(비율 2.37)에 그렸다.

**세로가 가로보다 3.56배 더 압축된다.** 황소 동상·전광판·환전소가 전부
알아볼 수 없는 어두운 덩어리가 됐다. 핫스폿 사각형만 제자리에 떠 있다.

## 02_cropped — 비율 맞춰 잘라 넣기

320:135 비율로 자르려면 1024×432 만 쓸 수 있다 — **원본 세로의 28%.**
바닥에 가까운 띠를 골라 잘랐다.

왜곡은 사라졌지만 **주문서에 적은 오브젝트 6개가 전부 잘려 나갔다.**
남은 것은 돌바닥이고, 핫스폿은 빈 포장도로를 가리킨다.

## 결론

> **세로 그림과 가로 무대는 양립하지 않는다.**

배경을 게임에 넣으려면 월드 스테이지가 세로가 되어야 한다
(기획서 §05 Modern UI Shell). **셸이 배경보다 먼저다.**
